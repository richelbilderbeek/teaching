# Instats

Instats helps proving teaching content.

To receive [a certificate worth 2 EC](Instats_Certificate_88538.pdf):

- Register at <https://instats.org>
- Go to a free seminar, such as [the Foundations of Bioinformatics](https://instats.org/seminar/foundations-of-bioinformatics-free-semin-1)
- Watch some seconds of the seminar
- Wait: you will receive an email with your certificate
