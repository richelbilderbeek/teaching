# Evaluation using rubrics

## Introduction

Most courses are evaluated by its learners.
Learners, however, are not teachers
and can be misguided on what teaching quality is.
For example, students values lecture higher than
active teaching, even though lectures results in lower
grades `[Deslauriers et al., 2019]`.

An alternative is to use scientifically informed
checklists of what good teaching is.

## Research question

What are the checklists available?
